# 🔖 ほんのしおり

好きなページを写真に撮って、本ごとにしまっておける読書記録アプリです。

- 📷 好きなページを撮影して、本ごとにまとめて保存（何枚でも）
- 📝 ページごとにひとことメモ
- 🏷️ 自由に作れるタグ（名前・色の変更、削除もOK）
- ★ いちばん好きなページが本棚の表紙になる
- 🗂️ 本ごとの一覧と、タグごとの一覧（新しい順・古い順・本ごとで並べ替え）
- 🔍 写真の文章を端末内で読み取る（縦書き・横書き）。Googleレンズなどでコピーした文章の貼り付けも可
- ✏️ 読み取った文章を縦書きで表示し、元の写真を見ながら手で直せる
- 🖍 文章の一部を選んでマーカーを引ける（文章を直しても位置を追いかける）
- 📤 他のアプリから共有された文章や画像を受け取れる（ホーム画面に追加したとき）
- 💾 バックアップの書き出し・読み込み

## 使い方

スマホのブラウザで公開URLを開き、「ホーム画面に追加」するとアプリのように使えます。

## データについて

写真・文章・メモ・マーカーは**使っている端末のブラウザの中だけ**に保存されます。サーバーには何も送りません。
文字の読み取りも端末の中で行い、写真や文章を外部に送ることはありません。
機種変更の前などは、「設定」→「書き出す」でバックアップを取っておいてください。

## 試験版

`https://okitakunai.github.io/hon-shiori-beta/` は試験版です。同じ `okitakunai.github.io` の下にありますが、データベース名（`hon-shiori-beta`）・localStorage・キャッシュ名・アプリ名を本番と分けているので、本番のデータには触れません。

## 旧版に戻す手順（データベース v2 への移行で不具合が出たとき）

文字認識を入れた版から、データベースが v2 になります。旧版（v1）のコードは v2 のデータベースを開けないので、**旧版のコードをそのまま戻してはいけません**。

**反映の前に**：本番の「設定」→「書き出す」でバックアップを保存しておいてください。反映の手順全体（書き出し・main への統合・確認・戻し方）は [RELEASE.md](RELEASE.md) にまとめています。

**戻すとき**：
1. ブランチ `rollback/v1-compatible` を main に反映します。これは旧版のコードに「データベースを版の指定なしで開く」修正だけを加えたもので、v2 のデータベースをそのまま開けます（追加された項目は使わずに残ります）。
2. スマホでアプリを開き直します（反映まで1〜2分。開き直しても古い画面のままなら、もう一度開き直す）。本・ページ・メモ・タグがそのまま見えれば完了です。

**それでもデータが開けないとき（最終手段）**：
1. Chrome の「設定」→「サイトの設定」→「すべてのサイト」→ `okitakunai.github.io` →「データを削除」。**この操作は試験版のデータも一緒に消えます。**
2. アプリを開き直し、「設定」→「読み込む」で、反映前に保存したバックアップを選びます。

## しくみ

HTML / CSS / JavaScript だけで動く静的なWebアプリです（ビルド不要）。データの保存には IndexedDB を使っています。

## 文字の読み取り（OCR）のしくみ

[Tesseract.js](https://github.com/naptha/tesseract.js) を使い、ブラウザの中（Web Worker）で読み取ります。エンジンと日本語の学習済みデータ（縦書き用 `jpn_vert`・横書き用 `jpn`）はこのリポジトリの `vendor/` に同梱していて、同じサイトから取得します（外部のサービスやCDNには通信しません）。言語データは使う向きの分だけ、初回の読み取りの前に確認してから取得し、以後は端末内に保存されたものを使います。
